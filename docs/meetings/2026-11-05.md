## 3. 논의 내용과 결정 사항 (이유 포함)

1. **3팀 관련 good first 이슈 검토**
    - 스프링 발판 추가(#20)는 기존 발판 생성 방식과 캐릭터 점프 동작의 연계가 필요하므로, 구현 방식을 검토한 후 추가 여부를 결정하기로 함 - 기존 발판 생성 방식과 캐릭터 점프 동작을 연계하는 기능으로, 게임의 핵심 동작을 확장하고 기존 코드와의 연동을 검토하기에 적합하다고 판단했기 때문
2. **중간발표 PPT 제작**
    - 윤한희가 피그마를 활용하여 PPT를 제작하기로 결정함. - 슬라이드 디자인과 형식을 통일하여 발표 자료의 일관성을 확보하기 위함.
3. **중간발표 발표 분담**
    - 김채윤(팀장): 목차, 팀 소개, 기능 소개, 진행 상황
    - 이민범(개발 리드): 회원 기능 구현, DB 테이블 구현, 남은 계획
    - 윤한희(리뷰·품질 담당): 분실물·습득물 등록, 협업 기록
    - 박유진(문서 담당): 분실물 검색검색, 타 팀 기여, 문제와 대응
    
    이유: 각 담당자가 관련 기능을 설명하고, 그 외 항목은 역할과 발표 분량을 고려하여 배분하기로 결정
