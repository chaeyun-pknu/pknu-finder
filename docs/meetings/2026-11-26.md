## 3. 논의 내용과 결정 사항 (이유 포함)

#### **1. 타 팀 기여 진행 상황 및 협업 방식 논의**

- 타 팀 기여 작업의 진행 상황을 확인하고, 코드 구현 완료 후 PR 제출 및 병합까지 완료되면 해당 기여 작업을 종료하기로 함.
- 각자 작업 브랜치를 생성하여 개발한 뒤, 공통 브랜치인 `feature/spring-platform`에 병합하기로 결정함.
- 공통 브랜치에 통합한 후 기능을 확인하고, 3조 원본 저장소에 최종 PR 1개를 제출하기로 협의함.

**이유:** 개별 작업을 공통 브랜치에 통합하여 기능 간 충돌을 줄이고, 통합된 코드의 동작을 확인한 후 원본 저장소에 제출하기 위함.

#### **2. 주요 기능 구현 및 DB 기능 동결 여부 확인**

- 홈, 마이페이지, 북마크 및 DB 관련 기능의 구현과 DB 기능 동결이 완료되었는지 확인하기로 함.
- `DB.database.py` 내 DB 처리 관련 함수 최적화 및 검색 관련 DB 최적화 내용을 점검하기로 함.
- `views.common.util.py` 내 공통 상수 및 함수 통합 여부를 확인하기로 함.

**이유:** 주요 기능의 구현 완료 여부를 점검하고, DB 처리 및 공통 코드의 최적화를 통해 프로젝트의 안정성과 유지보수성을 높이기 위함.

- 홈 화면
    - 사이드바, 배너, 제목, 설명, 최근 등록된 게시글  구현 완료.
    - 계획한 모든 기능 구현이 완료됨에 따라 기능 동결. 이후 추가 버그 발생 시 수정 예정
- 검색
    - 검색 유형(전체·분실물·습득물)과 카테고리·장소·날짜 필터를 통한 게시글 검색 기능 구현 완료.
    - 검색 결과에 게시글 정보와 이미지를 표시하고, 검색 결과가 없거나 검색 조건이 누락된 경우 안내 메시지가 표시되도록 구현함.
    - 전체 게시글 페이지에 CSS를 적용하고, 페이지네이션을 통해 한 페이지에 게시글 9개씩 표시되도록 개선함.
    - 검색 기능의 추가 개선 및 확인이 필요한 사항 발생 시 수정하기로 함.
- 등록
    - 분실물·습득물 정보 입력 및 등록, 사진 업로드·미리보기·삭제, 태그 관리, 구역별 장소 선택 기능 구현 완료.
    - 게시글 상세보기·수정 기능 구현 및 화면 간 이동·뒤로가기 동작 통일.
    - 중복 등록 방지, 등록 완료 알림 및 입력 폼 초기화 기능 구현·점검 완료.
    - 동결 여부**:** 주요 기능 구현 완료로 동결 가능.
- 마이페이지
    - OAuth를 활용한 로그인, 로그아웃, 회원 탈퇴 기능 구현 완료.
    - 북마크 기능 및 개인화 서비스 구현 완료.
    - 계획한 모든 기능 구현이 완료됨에 따라 기능 동결. 이후 추가 버그 발생 시 수정 예정
- 채팅
    - 채팅방 목록 및 채팅방 상세 화면 UI 구현 완료
    - DB 연동 완료 후 채팅방 목록 조회, 채팅 메시지 저장 및 조회 기능 구현 완료,
    - 사용자별 채팅방 접근 및 메시지 송수신 기능 구현 완료
    - 메시지 전송 후 발생하는 지연, 채팅방 진입 시 반복적인 인증 요청으로 인한 화면 깜빡임 현상 등 버그 이슈 등록 후 수정 완료.
    - 메시지 전송 과정에서 발생할 수 있는 예외 처리 및 오류 안내 작성 완료
- DB
    - Table, Auth, Storage, RLS 설정 등 주요 기능의 설정 완료
    - 추후 배포 시 Auth와 관련된 설정 적용 예정.
    - 이외 기능은 모두 동결 후 버그 발생 시 수정 예정.

#### **3. 버그 수정 및 DB 개선 사항 논의**

- 게시글 중복 등록 문제 등 발생한 버그의 수정 방향을 논의하기로 함.
    - 버그 수정 과정에서 DB 구조 및 처리 로직의 수정이 필요한지 확인하기로 함.
    - 수정 방향 논의 후 게시글 요청 시 `submission_id`를 이용하여 DB 중복 방지 방식을 채택함. (관련 이슈 #127, PR #129)
- 홈 화면, 검색, 마이페이지 등에서 아이템 카드를 DB 데이터에서 불러오는 과정에서 발생하는 지연을 줄이기 위해 데이터를 나누어 불러오는 방식으로 개선하기로 함. (관련 이슈 #107, #128, PR # )

**이유:** 게시글 중복 등록을 방지하고, 아이템 카드 로딩 과정에서 발생하는 지연을 줄여 사용자 편의성을 개선하기 위함.

#### **4. 공통 CSS 수정 계획**

- 김채윤이 전체 공통 CSS를 수정하고, 프로젝트 전반의 색상을 통일하기로 함.

**이유:** 화면별로 상이한 색상 및 스타일을 통일하여 프로젝트 UI의 일관성을 높이기 위함.
