## 3. 논의 내용과 결정 사항 (이유 포함)

- 타 팀 기여 계획 및 역할 분담: 구현(이민범, 윤한희), 실행 및 기능 확인(김채윤), PR 설명 작성 및 회의록 기록(박유진)으로 역할을 분담함. → 담당 업무를 명확히 하여 작업 중복을 방지하고 효율적인 협업을 진행하기 위함.
- 날짜 필터: 기존 방식에서 변경하지 않기로 결정함. → 기존 기능의 일관성을 유지하고 불필요한 수정 작업을 줄이기 위함.
- 장소 드롭다운: A~E 구역별로 건물을 분류하고 `A12 웅비관`, `A13 누리관`과 같이 건물 코드와 이름을 함께 표시하며, 백경광장, 잔디밭, 정문, 후문, 교내 보행로 등은 기타 장소로 분류하기로 함. → 장소를 체계적으로 관리하고 사용자가 원하는 위치를 쉽게 선택할 수 있도록 하기 위함.
- 상세보기 구현 방식: 상세보기 기능을 별도 함수로 구현하고 검색 화면에서 버튼 클릭 시 해당 함수를 호출하는 방식으로 진행하기로 함. → 코드 재사용성을 높이고 기능 관리 및 유지보수를 편리하게 하기 위함.
- 홈 화면 게시글 표시: 최근 등록된 게시글 일부만 표시하기로 함. → 홈 화면을 간결하게 구성하고 주요 게시글을 빠르게 확인할 수 있도록 하기 위함.
- 검색 화면 게시글 표시: 전체 게시글을 대상으로 검색할 수 있도록 구현하기로 함. → 사용자가 원하는 게시글을 제한 없이 검색할 수 있도록 하기 위함.
- 추가 논의 사항: 장소 드롭다운의 세부 항목 및 기타 구현 사항은 추후 논의를 통해 확정하기로 함. → 실제 구현 과정에서 필요한 사항을 반영하기 위함.
